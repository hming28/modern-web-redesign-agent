# I-KO Soya Brand Spec

## Direction
Premium Fresh: a clean, warm, food-focused 2026 redesign that keeps I-KO Soya recognizable through real logo, product photography, and video assets.

- Logo: `/image/logo_nb.png`, `/image/Iconlogo.png`

## Color System
- Soy cream background: `#f8f2e7`
- Warm white panels: `#fffdf8`
- Roasted bean text/accent: `#4c3927`
- Soft gold highlight: `#d8a93b`
- Fresh sage support accent: `#7c9b78`
- Purple potato accent: `#79608f`

## Typography
- Display: Georgia / Iowan Old Style / Times New Roman stack for refined food-editorial headings.
- Body and UI: Avenir Next / Segoe UI / Helvetica Neue / Arial stack for readable navigation and descriptions.

## Interaction
- Header is fixed, translucent, and compact.
- Cards lift subtly on hover.
- Reveal motion uses IntersectionObserver and respects `prefers-reduced-motion`.
- Dark theme is supported with the same token names.
